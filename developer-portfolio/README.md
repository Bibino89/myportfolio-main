# Developer Portfolio

A responsive dark-modern developer portfolio built with Next.js App Router, TypeScript and Tailwind CSS v4.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Personalize before publishing

The portfolio has been populated using the supplied resume. Review the public contact details, project descriptions and resume PDF before deployment. The resume is available at `/resume.pdf`.

The KCAS project entry is a high-level portfolio summary based on the technologies and workflows discussed. Do not publish client-confidential details, internal URLs, credentials, private data or screenshots without permission.

## Build

```bash
npm run build
```
